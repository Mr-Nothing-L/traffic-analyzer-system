## 一、标注数据格式说明

### 1.1 输出字段定义

| 字段名 | 字段说明 | 描述 |
|--------|----------|------|
| chunk | 视频块 | 原视频切片后的视频块,一个视频块应包含一类完整事件,序号从 1 开始,例如 chunk #1、chunk #2 |
| idx | 事件主体目标 id | 暂未使能,默认值为 1 |
| action | 事件类型 | 当前视频块中存在的事件类型,具体参见下文的「事件类型定义」 |
| description | 事件描述 | 当前视频块中存在的事件类型的全部描述,具体参见下文的「事件类型定义」 |
| start_timestamp | 开始时间 | 当前视频块开始时间点,例如一个待标注视频的 0-5s 为一个完整违停事件,则违停视频块的开始时间为 0.000 |
| end_timestamp | 结束时间 | 当前视频块结束时间点,例如一个待标注视频的 0-5s 为一个完整违停事件,则违停视频块的结束时间为 5.000 |
| chunk_name | 视频块名称 | 视频块名称,命名格式:`事件类型_视频文件名称_idx.mp4` |

### 1.2 通用标注原则

1. 参照事件类型定义并依据视频实际情况标注即可;
2. 存在不明确事件时,标注所有可能事件类型。例如:机动车一直压在应急车道线上,则同时标注**占用车道事件**以及**违停事件**;
3. 若相同时间段内同时发生两类事件(例如,施工事件都会伴随行人/施工人员事件),这种情况下的视频块中两类事件都要标注;
4. 用于标注的数据样本文件格式:`.mp4`、`.avi`;
5. 标注后,目标信息文件格式:`.json` + `.mp4`。

## 二、事件类型定义

### 2.2 大模型标注补充说明

1. 大模型的事件检测标注,按照常见思维逻辑判断。
2. 大模型检测标注,给出关键事件就行了。例如事故拥堵同时发生,此时给出事故即可。
3. 特殊事件(即标注工程师无法确认时),单独与产品经理确认。
4. 标注时,若遇到视频出现卡帧、拖影、码率低、分辨率极差等现象,可丢弃不标注。

**🆕 v4.5 新增 (20260424) — 视频时长与切分规则:**

5. 若视频时长少于 5s,可视为异常数据,不作标注;
6. 若短时间事件(例如实线变道等)在开头结尾,可进行切分只保留部分(事件完整且不要低于 5 秒的阈值即可);
7. 若整段视频长度超过 15 秒,可进行切分只保留 15 秒(要求保留其中包含的短时间事件)。

## 三、验收标准

### 3.1 各事件类型的验收条件

| 事件标注值 | 事件类型 | 验收标准 |
|------------|----------|----------|
| 1 | 机动车违停 | 边界条件:车辆大小不小于 30×30 |
| 2 | 机动车占用应急车道 | 边界条件:车辆大小不小于 30×30 |
| 3 | 交通事故 | — |
| 4 | 行人/施工人员 | 边界条件:行人大小不小于 25×50 |
| 5 | 非机动车 | — |
| 6 | 拥堵 | — |
| 7 | 施工 | — |
| 8 | 逆行 | 边界条件:车辆大小不小于 30×30;且车辆位移不小于车辆纵向像素数 |
| 9 | 无典型事件 | — |
| 10 | 抛洒物 | 边界条件:抛洒物大小不小于 10×10 |
| 11 | 实线变道 | 边界条件:车辆大小不小于 30×30 |

### 3.2 事件分割规则

- **事件之间无交集**:
  1. 其他事件和无事件(class 9)发生前后五秒内可以保留,超过了需要分割;
  2. 除事件 9 以外,其他事件之间无时间交集就要分割;
  3. 同一类型事件隔了几秒又发生的不需要分割。

- **视频分割时机**:事件有时间交集无需分割,取并集;事件无时间交集则需要分割。

- **事件标注范围**:高速路段内。
